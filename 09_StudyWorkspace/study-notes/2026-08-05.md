## Day 3 闭卷复习

### 1. async 函数不写 await，得到的是什么？

我的回答：得到的不是一个数值，而是一个coroutine对象

订正：调用 `async def` 定义的函数但不写 `await`，得到的是 coroutine（协程）对象，而不是函数最终声明的返回值。使用 `await` 后，才能执行协程并取得真正结果。
更准确地说：
result = service.chat()
此时 result 是协程对象：
<coroutine object ChatService.chat at ...>
只有：
result = await service.chat()
才会执行协程，并取得它最终返回的 LLMResult。
需要注意，异步函数最终返回的不一定是“数值”，也可能是字符串、对象或其他类型。
### 2. Router、ChatService、LLM Provider 分别负责什么？

我的回答：Router负责HTTP请求，chatservice负责业务，LLM Provider负责与大模型交流

订正：
Router
负责 HTTP 层：
    接收请求
    解析参数

    调用 Service

    接收业务输入

    以后可以加入权限、历史记录、Token 统计等业务规则

LLM Provider
负责模型调用：
    MockLLM

    DeepSeek
    Ollama
    其他外部模型服务

- Router 负责 HTTP 请求、参数校验和响应转换。
- ChatService 负责聊天业务流程和业务规则。
- LLM Provider 负责与某个具体模型或外部模型服务交互。
