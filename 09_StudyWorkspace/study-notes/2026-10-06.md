# 二十四、LeetCode 1283 独立实现

## 我的代码

```cpp
class Solution {
public:
    int smallestDivisor(
        vector<int>& nums,
        int threshold
    ) {
        int left = 1;

        int right =
            *max_element(
                nums.begin(),
                nums.end()
            );

        while(left < right){
            int mid =
                left + (right - left) / 2;

            long long int divs = 0;

            for(int num : nums){
                divs +=
                    (num + mid - 1) / mid;

                if(divs > threshold){
                    break;
                }
            }

            if(divs > threshold){
                left = mid + 1;
            }
            else{
                right = mid;
            }
        }

        return left;
    }
};
```

# 二十七、复杂度

## 我的回答

> 时间复杂度 = O(n logM) M代表数组最大的元素，搜索区间为[1, M],所以二分查找的复杂度为O(logM),n代表数组的大小，即每个答案候选需要遍历的次数
>
> 额外辅助空间复杂度 = O(1)，只增加了几个常数变量

## 订正

结论完全正确：

```text
O(n log M)
```

其中：

```text
n = nums.size()
M = max(nums)
```

一次可行性判定：

```text
O(n)
```

答案空间二分：

```text
O(log M)
```

总：

```text
O(n log M)
```

额外空间：

```text
O(1)
```

### 面试专用回答

> 对 divisor 的答案空间 `[1,max(nums)]` 做二分。每次候选 divisor 需要遍历 n 个元素计算总和，因此一次判定为 O(n)；答案空间二分需要 O(log M) 轮，所以总时间复杂度是 O(n log M)，额外空间 O(1)。

# 三十九、集中定义固定 API Error

如果多个 Handler 都可能出现：

```text
INVALID_NAME
```

不应该反复：

```go
APIError{
    Status:  400,
    Code:    "INVALID_NAME",
    Message: "name is required",
}
```

而是：

```go
var ErrInvalidName = APIError{
    Status:  http.StatusBadRequest,
    Code:    "INVALID_NAME",
    Message: "name is required",
}
```

Handler：

```go
if name == "" {
    writeError(
        w,
        ErrInvalidName,
    )
    return
}
```

# 四十、Stage 3 检查 1

## 我的回答

> 因为如果请求变多，不同的handler如果发生同一种错误那么就要重复得构造改错误类型结构，重复地填写statu code message等字段值，所以应该将该错误结构转换成错误定义，并且这个错误的字段值都是静态不变的，所以适合全局地将其定义为一个明确的错误类型，这样handler只需要选择具体发生了哪个错误即可，不需要再重复地填写statu code message等字段值，提高了代码的一致性和维护性

## 订正

理解完全正确。

术语修正：

```text
ErrInvalidName
```

不是新的 Go 类型。

真正类型：

```text
APIError
```

`ErrInvalidName` 是：

```text
预定义的APIError错误值
```

。

### 相关示例

集中定义可以避免：

```text
同一个Code
不同Status

同一个Code
不同默认Message
```

等不一致。

### 面试专用回答

> 对固定 API 错误进行集中定义，可以让多个 Handler 共享同一份 Status、Code 和 Message，避免重复构造和错误定义不一致，同时使 Handler 只需要表达发生了哪一种错误。
