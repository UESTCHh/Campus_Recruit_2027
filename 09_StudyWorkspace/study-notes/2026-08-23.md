3. STL vector
创建：
vector<int> nums;

添加：
nums.push_back(1);
nums.push_back(2);
nums.push_back(3);

遍历
普通方式：
for(auto x:nums)
{
    cout<<x;
}
特点：
会发生拷贝。

引用方式：
for(auto& x:nums)
{
    cout<<x;
}
特点：
不发生拷贝
可以修改原元素

只读引用：
for(const auto& x:nums)
{
    cout<<x;
}
特点：
不复制
不允许修改
适合大型对象遍历。

今日问题
1. new创建对象后生命周期如何管理？
我的回答：
new创建的对象应该在生命周期结束后用delete的方式释放掉内存，并且将原先指向该内存的指针置空，防止访问野指针。

订正：
new创建的对象存储在堆区，生命周期由程序员手动管理。
对象生命周期结束后：
需要：
delete p;
p=nullptr;
释放内存。
delete后如果不置空：
指针仍保存原地址。
此时称为：
悬空指针(dangling pointer)

2. 构造函数和析构函数分别什么时候调用？
我的回答：
构造函数在创建对象时自动调用，析构函数在对象生命周期结束后自动调用。

订正：
正确。
构造函数：
对象创建时调用。
作用：
完成初始化。
析构函数：
对象生命周期结束时调用。
作用：
释放资源。
普通对象：
Student s;
离开作用域后：
自动调用析构函数。
动态对象：
Student* p = new Student();
需要：
delete p;
才调用析构函数。
执行顺序：
delete p

↓

调用析构函数

↓

释放堆内存

3. vector遍历时auto、auto&、const auto&区别？
我的回答：
auto会复制拷贝元素，auto&不会复制，const auto&既不会复制也不能修改。

订正：
写法	是否拷贝	是否修改
auto x	是	修改副本
auto& x	否	修改原元素
const auto& x	否	不能修改
