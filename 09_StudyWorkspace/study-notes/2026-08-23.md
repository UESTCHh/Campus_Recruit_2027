今日问题
new创建对象后生命周期如何管理？
答：new创建的对象应该在生命周期结束后用delete的方式释放掉内存，并且将原先指向该内存的指针置空，防止访问野指针。
订正：
new创建的对象存储在堆区，生命周期由程序员手动管理。

当对象生命周期结束后，需要通过delete释放对应内存，并将指针设置为nullptr，避免后续访问已经释放的内存导致野指针问题。


例如：

```cpp
int* p = new int(20);

delete p;
p = nullptr;

构造函数和析构函数分别什么时候调用？
答：构造函数在创建对象时自动调用，析构函数在对象生命周期结束后自动调用。
订正：
构造函数在对象创建时自动调用，主要用于完成对象初始化。
析构函数在对象生命周期结束时自动调用，主要用于释放资源，例如：
动态申请的内存
文件句柄
网络连接等资源
普通对象：
Student s;
在离开作用域后自动调用析构函数。
动态对象：
Student* p = new Student();

delete p;
需要delete后才会调用析构函数。

vector遍历时auto、auto&、const auto&区别？
答：直接auto会复制拷贝元素，auto&引用的方式不会复制拷贝元素，const auto&只读引用的方式既不会复制拷贝元素，也不会修改元素。
订正：
auto
for(auto x:nums)
会复制vector中的元素。
特点：
修改x不会影响原vector
对大对象遍历时存在额外拷贝开销

auto&
for(auto& x:nums)
使用引用访问元素。
特点：
不发生拷贝
可以直接修改vector中的元素

const auto&
for(const auto& x:nums)
使用const引用访问元素。
特点：
不发生拷贝
不允许修改元素
适合遍历大型对象或只读场景

总结：
写法	是否拷贝	是否可以修改
auto x	是	可以修改副本
auto& x	否	可以修改原元素
const auto& x	否	不能修改

另外补充两个小细节：

### 1. 关于 `delete + nullptr`

你的原回答：

> 防止访问野指针

准确，但稍微严谨一点：

`delete` 本身释放内存，但是**不会自动让指针失效**：

```cpp
int* p = new int(10);

delete p;

// p仍然保存原地址
此时 p 叫悬空指针（dangling pointer）。
设置：
p=nullptr;
以后：
if(p)
{
    ...
}
可以安全判断。
2. 析构函数
你的回答：
析构函数在对象生命周期结束后自动调用。

正确。
但是面试中可能追问：
new出来的对象析构函数什么时候调用？

例如：

delete p;
执行顺序：

 |
 ↓
调用 ~Student()
 |
 ↓
释放堆内存
