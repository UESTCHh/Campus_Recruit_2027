# 二、C++ 学习内容

## Stage 1：LC102 二叉树的层序遍历

### 1. 核心原理

层序遍历（Level Order Traversal）属于广度优先搜索 BFS。

BFS 使用队列实现。

队列具有先进先出（FIFO）的特点：

- 先进入队列的节点先被处理。
- 每次处理一个节点时，将它的左右孩子加入队列。
- 由于先处理上一层的节点，下一层的节点只能在上一层之后被处理，因此自然形成从上到下的层序遍历。

### 2. 为什么需要 levelSize？

每层开始时记录：

```cpp
int levelSize = bfs.size();
```

这是因为处理当前层节点时，会不断将下一层节点加入队列。

如果不提前记录当前层节点数量，而是直接遍历到队列为空，就无法准确区分当前层和下一层。

因此：

```cpp
for(int i = 0; i < levelSize; i++)
```

保证每次循环只处理当前层的节点。

### 3. 独立编码

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> ans{};
        if(root == nullptr){
            return ans;
        }

        queue<TreeNode*> bfs;
        bfs.push(root);

        while(!bfs.empty()){
            int levelSize = bfs.size();
            vector<int> temp{};

            for(int i = 0; i < levelSize; i++){
                TreeNode* front = bfs.front();
                bfs.pop();

                if(front->left != nullptr){
                    bfs.push(front->left);
                }

                if(front->right != nullptr){
                    bfs.push(front->right);
                }

                temp.push_back(front->val);
            }

            ans.push_back(temp);
        }

        return ans;
    }
};
```

**验收：LeetCode 102 提交通过。**

### 4. 复杂度分析

时间复杂度：

\[
O(n)
\]

每个节点最多入队一次、出队一次，每次处理只涉及常数次操作。

辅助空间复杂度：

\[
O(w)
\]

其中 w 是二叉树的最大宽度，主要来自 BFS 队列。

如果计算最终结果数组：

\[
O(n)
\]

因为需要保存全部 n 个节点的值。

## Stage 2：LC199 二叉树的右视图

### 1. 核心思路

题目要求从二叉树右侧观察，返回每一层能够看到的节点。

由于 BFS 每一层按照从左到右的顺序遍历，因此：

- 左视图：每层第一个节点。
- 右视图：每层最后一个节点。

所以只需要在层序遍历时判断：

```cpp
if(i == levelSize - 1){
    ans.push_back(front->val);
}
```

### 2. 独立编码

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> ans{};

        if(root == nullptr){
            return ans;
        }

        queue<TreeNode*> bfs;
        bfs.push(root);

        while(!bfs.empty()){
            int levelSize = bfs.size();

            for(int i = 0; i < levelSize; i++){
                TreeNode* front = bfs.front();
                bfs.pop();

                if(front->left != nullptr){
                    bfs.push(front->left);
                }

                if(front->right != nullptr){
                    bfs.push(front->right);
                }

                if(i == levelSize - 1){
                    ans.push_back(front->val);
                }
            }
        }

        return ans;
    }
};
```

**验收：LeetCode 199 提交通过。**

### 3. 复杂度分析

时间复杂度：

\[
O(n)
\]

每个节点最多入队一次、出队一次。

辅助空间复杂度：

\[
O(w)
\]

主要来自 BFS 队列。

结果数组空间复杂度：

\[
O(h)
\]

每层保存一个节点，h 为树的高度。

### 4. 代码优化

最初代码中定义了：

```cpp
vector<int> temp{};
```

但实际上没有使用，可以删除。

这是代码简化，不属于算法复杂度优化。

### 5. BFS 的通用模板

今天两道题可以统一成一个模板：

```cpp
queue<TreeNode*> bfs;
bfs.push(root);

while(!bfs.empty()){
    int levelSize = bfs.size();

    for(int i = 0; i < levelSize; i++){
        TreeNode* cur = bfs.front();
        bfs.pop();

        // 处理当前节点

        if(cur->left != nullptr){
            bfs.push(cur->left);
        }

        if(cur->right != nullptr){
            bfs.push(cur->right);
        }
    }
}
```

不同题目的区别主要是每层需要保存什么信息。

- LC102：保存当前层所有节点。
- LC199：保存当前层最后一个节点。
- 左视图：保存当前层第一个节点。

### 3. 错误包装示例

后续需要掌握：

```go
return fmt.Errorf("get student: %w", err)
```

其中 `%w` 会包装原始错误并保留错误链。

与之对比：

```go
return fmt.Errorf("get student: %v", err)
```

`%v` 只格式化错误信息，不会保留可供 `errors.Is` 和 `errors.As` 沿用的包装关系。
