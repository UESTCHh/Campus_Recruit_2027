# 三、Stage 1：LC658 与 LC973 对比

题目：

```text
给定一个已经升序的数组 arr，

```

例如：

```text
arr = [1,2,3,4,5]

x = 3
```

答案：

```text
[1,2,3,4]
```

## 检查1

### 我的回答

> 能用heap，可以将元素到整数x的距离作为priority维护Size-k Max heap；但不应该第一优先想到heap，因为本身题目给定的输入数组有比较清晰的排序结构，可以利用该排序信息帮助解题，比如可以利用二分查找+双指针的方式构成算法

完全正确。

Heap方案：

```text

```

但是没有充分利用：

```text

```

```text

+

```

```text

```

> LC658 可以使用 Size-K Heap，但数组已经升序，因此更适合利用有序结构。可以先通过二分定位 x 附近，再使用双指针向两侧选择距离最近的 K 个元素。

# 八、为什么使用 lower_bound 思维

目标不是：

```text
判断x是否存在
```

而是：

```text
找到x在有序数组中的分界位置
```

即：

```text
第一个 >= x 的位置
```

例如：

```text
arr = [1,3,5,7,9]
x = 6
```

得到：

```text
left → 5
right → 7
```

即使：

```text
6不存在
```

算法仍然自然成立。

# 九、双指针 tie-break

当：

```text
x - arr[left]
==
arr[right] - x
```

题目要求：

```text
较小元素优先
```

由于数组升序：

```text
arr[left] < arr[right]
```

所以条件：

```cpp
x - arr[left]
<=
arr[right] - x
```

距离相同时选择左侧。

# 十五、LeetCode 658 Find K Closest Elements

## 我的代码

```cpp
class Solution {
public:
    vector<int> findClosestElements(vector<int>& arr, int k, int x) {
        int n = static_cast<int> (arr.size());
        vector<int> answer;
        int left = 0;
        int right = n - 1;
        int index = -1;

        while(left <= right){
            int mid = left + (right - left) / 2;

            if(arr[mid] < x){
                left = mid + 1;
            }
            else if(arr[mid] > x){
                right = mid - 1;
            }
            else{
                index = mid;
                break;
            }
        }

        if(left == n) index = n - 1;
        else if(right == -1) index = 0;
        else if(right < left) index = left;

        left = index - 1;
        right = index;

        for(int i = 0; i < k; i++){
            if(left < 0){
                right++;
            }
            else if(right > n - 1){
                left--;
            }
            else if(x - arr[left] <= arr[right] - x){
                left--;
            }
            else{
                right++;
            }
        }

        for(int i = left + 1; i < right; i++){
            answer.push_back(arr[i]);
        }

        return answer;
    }
};
```

# 十六、LC658代码订正

代码整体可以正确工作。

主要需要优化的是 Binary Search 模型。

原写法首先：

```text
精确查找x
```

如果没找到再：

```text
推导插入位置
```

而题目真正需要的是：

```text
第一个 >= x 的位置
```

所以标准边界二分更自然：

```cpp
int low = 0;
int high = n;

while (low < high) {
    int mid =
        low + (high - low) / 2;

    if (arr[mid] < x) {
        low = mid + 1;
    }
    else {
        high = mid;
    }
}

int right = low;
int left = right - 1;
```
