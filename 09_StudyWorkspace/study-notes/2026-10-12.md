# 3. LeetCode 349 两个数组的交集

代码：

```cpp
class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        unordered_set<int> set;
        unordered_set<int> ans;
        vector<int> answer;

        for(int num : nums1){
            set.insert(num);
        }

        for(int num : nums2){
            if(set.find(num) != set.end()){
                ans.insert(num);
            }
        }

        for(auto num : ans){
            answer.push_back(num);
        }

        return answer;
    }
};

思路
第一步：
保存 nums1 中出现过的元素：
nums1
 |
 ↓
HashSet

第二步：
遍历 nums2：
判断：
当前元素是否存在于HashSet

如果存在：
加入答案集合。
第三步：
使用结果 HashSet 去重。
复杂度分析
设：
n = nums1长度
m = nums2长度

时间复杂度：
O(n + m)

原因：
- 遍历 nums1
- 遍历 nums2
- 哈希查找平均 O(1)
空间复杂度：
O(n + m)

原因：
需要保存：
- nums1集合
- 答案集合

四、面试专用回答
1. Go如何访问数据库？
回答：
Go 通常通过 database/sql 包访问数据库，它提供统一的数据库操作接口，再通过具体数据库驱动连接实际数据库。程序启动阶段创建 sql.DB 对象管理数据库连接池，业务代码通过 Query 或 Exec 执行 SQL，查询结果通过 rows.Next 遍历，并使用 Scan 映射到 Go 变量中。

2. sql.DB是什么？
回答：
sql.DB 不是一个数据库连接，而是 Go 中用于管理数据库连接池的对象。它负责连接的创建、复用和管理，避免每个请求重复创建数据库连接，提高数据库访问效率。

3. 为什么数据库连接不放Handler中？
回答：
Handler应该专注于HTTP请求处理和业务调用，而数据库连接属于应用生命周期资源，通常在程序启动阶段初始化，并通过依赖注入传递给业务层使用。
