# 五、频率统计

数组：

```text
4 4 4 2 2 8 8 8 8 3
```

统计：

```text
4 → 3
2 → 2
8 → 4
3 → 1
```

如果：

```text
k = 2
```

频率最高的是：

```text
8 → 4次
4 → 3次
```

所以：

```text
Top 2 Frequent
→ 8 4
```

# 十八、Go 预热问题 2

## 问题

为什么 Server 返回 JSON 时也应该告诉 Client：

```http
Content-Type: application/json
```

？

---

## 我的回答

> 因为这样Client能通过Response Header得知响应的内容格式，这样就可以使用相应的Json Decoder去解析响应内容，而不用提前判断内容格式再处理，提升效率

---

## 订正

前半部分正确。

核心应该表达为：

```text
Content-Type
→ 告诉Client Response Body应该按照什么媒体类型解释
```

例如：

```http
Content-Type: application/json
```

表示：

```text
Response Body
→ JSON
```

而：

```http
Content-Type: text/plain
```

表示：

```text
Response Body
→ 普通文本
```

这里最核心的意义不是：

```text
提升效率
```

而是：

> Client 不需要通过猜测 Body 内容来判断格式，而可以依据 Response Header 明确知道 Body 的媒体类型。

---

## 相关示例

Response：

```http
HTTP/1.1 200 OK
Content-Type: application/json

{"name":"hui","age":22}
```

Client 看到：

```text
Content-Type
→ application/json
```

就知道：

```text
{"name":"hui","age":22}
```

应该作为：

```text
JSON
```

解释。

具体使用什么 JSON 解析工具：

```text
取决于客户端语言和框架
```

不一定是 Go 的 Decoder。

---

## 面试专用回答

> Server 返回 JSON 时应该设置 `Content-Type: application/json`，用于告诉 Client Response Body 的媒体类型。Client 可以据此选择正确的解析方式，而不需要通过猜测 Body 内容来判断数据格式。
